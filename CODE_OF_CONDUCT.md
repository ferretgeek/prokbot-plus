# 行为准则 / Code of Conduct

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)。

简单说：

- 友善、尊重地交流，对事不对人；
- 不骚扰、不人身攻击、不发布他人的隐私信息；
- 在 issue 和讨论里，不要贴任何人的密码、Key 或服务器地址。

违反准则的内容会被删除，严重时会封禁相关账号。需要举报时，用仓库的私密漏洞报告渠道，或联系仓库维护者。

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful, do not harass anyone or publish anyone's private information, and never post passwords, keys or server addresses. Content that breaks these rules will be removed, and serious cases lead to a ban. To report a problem, use the repository's private reporting channel or contact the maintainers.
